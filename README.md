# Food Ordering Application (React)

## Overview

This is a Food Ordering web application built using React. The project simulates an online food delivery platform where users can browse food items and add them to their cart.

## Features

* Food items listing
* Add to cart feature
* Responsive design
* Reusable components

## Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## What I Learned

* Managing state using React hooks
* Component-based architecture
* Handling user interactions
* Conditional rendering
* Building responsive layouts
